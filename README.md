# 🍲 אתר המתכונים – מדריך למשתמש

אתר לשמירה ושיתוף של מתכונים. כל משתמש יכול לשמור מתכונים פרטיים לעצמו, לשתף מתכונים עם כולם, לחפש מתכונים של אחרים ולסמן מועדפים.

---

## 🔗 כתובות

| מה | כתובת |
|---|---|
| **האתר** | _יעודכן בקרוב_ |
| **השרת (API)** | https://recipes-backend-ubmp.onrender.com/api |
| **תיעוד השרת (Swagger)** | https://recipes-backend-ubmp.onrender.com/api-docs |
| **בדיקת תקינות השרת** | https://recipes-backend-ubmp.onrender.com/api/health |

> 💤 **שימו לב:** השרת נמצא במסלול חינמי ו"נרדם" אחרי 15 דקות בלי שימוש. בכניסה הראשונה אחרי הפסקה, הטעינה עלולה לקחת **עד דקה**. זה תקין – פשוט ממתינים, ומשם הכול מהיר.

---

## 👤 משתמשי דוגמה

אפשר להיכנס עם המשתמשים האלה כדי לראות את האתר עם תוכן קיים:

| תפקיד | אימייל | סיסמה | מה רואים |
|---|---|---|---|
| **מנהל** | `<<למלא>>` | `<<למלא>>` | הכול, כולל ניהול קטגוריות ועריכת מתכונים ציבוריים |
| **משתמשת רגילה** | `sara@example.com` | `<<למלא>>` | מתכונים משלה (פרטיים וציבוריים) |
| **משתמש רגיל** | `david@example.com` | `<<למלא>>` | מתכונים משלו (פרטיים וציבוריים) |

רוצים לנסות כמשתמש חדש? לחצו **"הצטרפות חינם"** בראש האתר.

---

## 🧭 מה יש באתר

### לפני התחברות
- **דף הבית** – הסבר על האתר.
- **התחברות** / **הצטרפות חינם** – כדי לראות מתכונים צריך להיות מחוברים.

### אחרי התחברות (כל משתמש)

| עמוד | מה עושים בו |
|---|---|
| **מתכונים משותפים** | כל המתכונים הציבוריים של כל המשתמשים |
| **המתכונים שלי** | המתכונים שלי בלבד – גם הפרטיים וגם הציבוריים |
| **המועדפים** | מתכונים שסימנתי בלב ❤️ |
| **מתכון חדש** | הוספת מתכון, כולל תמונה |

### רק למנהל
- **ניהול קטגוריות** – הוספה, שינוי שם ומחיקה של קטגוריות.
- **עריכת מתכון ציבורי** של כל משתמש (למשל לתיקון טעות).

## 🔍 חיפוש וסינון

בראש רשימת המתכונים יש תיבת חיפוש ומסננים. אפשר לשלב כמה מסננים יחד:

| מסנן | אפשרויות |
|---|---|
| **חיפוש חופשי** | לפי שם המתכון, התיאור או הרכיבים |
| **קטגוריה** | מנות עיקריות, תוספות, סלטים, מרקים, עוגות, עוגיות, קינוחים, לחמים ומאפים |
| **מפרסם** 🆕 | הצגת המתכונים של משתמש מסוים (ליד כל שם מופיע מספר המתכונים שלו) |
| **רמת קושי** | קל / בינוני / קשה |
| **סוג תפריט** | בשרי / חלבי / פרווה |
| **זמן הכנה** | עד 5 דקות ... עד 60 דקות |
| **מיון** | מהחדש לישן, מהישן לחדש, זמן הכנה, שם המתכון (א-ת) |
| **ציבורי / פרטי** | רק בעמוד "המתכונים שלי" |

כדי לחזור לרשימה המלאה לוחצים **"✕ ניקוי סינון"**.

> 💡 החיפוש נשמר בכתובת הדף, כך שאפשר להעתיק את הקישור ולשלוח למישהו – והוא יראה בדיוק את אותן תוצאות.

---

## ✍️ הוספת מתכון

1. בעמוד **"המתכונים שלי"** לוחצים **"+ מתכון חדש"** (או **"+ הוספת מתכון"** בדף הבית).
2. ממלאים: שם, תיאור, קטגוריה, רכיבים, אופן הכנה, זמן הכנה, מספר מנות, רמת קושי וסוג תפריט.
3. בוחרים אם המתכון **ציבורי** (כולם רואים) או **פרטי** (רק אני רואה).
4. אפשר להוסיף תמונה: **JPG / PNG / WEBP, עד 5MB**.
5. לוחצים **שמירה**.

אפשר לערוך או למחוק מתכון בכל זמן מתוך עמוד המתכון.

## 🔐 כללים חשובים

- **סיסמה** – לפחות 8 תווים, עם לפחות אות אחת וספרה אחת.
- **התחברות נשמרת ליום אחד.** אחרי זה האתר יבקש להתחבר מחדש.
- **מתכון פרטי** – אף אחד אחר לא יכול לראות אותו, גם לא דרך קישור ישיר.
- **אחרי 20 ניסיונות התחברות שגויים** – אי אפשר לנסות שוב במשך 15 דקות (הגנה מפני פריצה).

## 🛠️ למפתחים

<details>
<summary>הרצה מקומית</summary>

1. מתקינים חבילות:
   ```bash
   npm install
   ```
2. מעתיקים את `.env.example` לקובץ חדש בשם `.env` ומגדירים בו את כתובת השרת:
   ```
   VITE_API_URL=https://recipes-backend-ubmp.onrender.com/api
   ```
   (או `http://localhost:3000/api` כשהשרת רץ במחשב.)
3. מריצים:
   ```bash
   npm run dev
   ```
4. פותחים בדפדפן: http://localhost:5173

**טכנולוגיות:** React, TypeScript, Vite, Redux Toolkit (RTK Query), React Router, React Hook Form, Tailwind CSS.

**קוד השרת:** https://github.com/lali507/recipes-backend
